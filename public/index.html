Reviewer Tips

  • Select high-quality voices like Microsoft Natural or Google voices from the toolbar dropdown.
  • Click ⏪ to rewind narration to the start, or 🔊 to pause and resume.
  • Press Space to flip cards and arrow keys to navigate.

Supported File Types

  • Images: PNG, JPG, JPEG, GIF
  • Documents: PDF, PPTX, TXT

Text-to-Speech Narration

  • Text-to-speech narration is supported for all uploaded content types.
  • Click the voice dropdown to select a preferred voice for text-to-speech narration.
  • Narration and text-to-speech features are supported for all uploaded content types.
  • Click the ⏪ button to rewind narration to the start, or 🔊 to pause and resume.

How to Save and Import Flashcards

  • Click Export JSON to download your flashcards as a JSON file.
  • Click Import JSON and select a saved JSON file to restore flashcards.
